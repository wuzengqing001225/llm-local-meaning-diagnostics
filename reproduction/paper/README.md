# Paper

`paper.pdf` is *When Local Definitions Matter: Diagnosing Source-Linked Language Model Errors* (under double-blind review). `source/paper.tex` assembles the main sections from `source/section/` and the appendix from `source/appendix/`. The bibliography, ICLR style files, and figures are also under `source/`. Build with `latexmk -pdf paper.tex` inside `source/`; see `source/SOURCE_LAYOUT.md` for the template check.
