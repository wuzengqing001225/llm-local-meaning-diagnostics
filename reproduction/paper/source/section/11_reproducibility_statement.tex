\subsubsection*{Reproducibility statement}
We release a risk index over 6,529 retained CUAD diagnostic questions, 1,500 of them with frontier-reader outcomes, together with question sets, reader outcomes, proxy scores, and an experimental command-line pipeline for new corpora. The GitHub repository includes model records, analysis scripts, and verification of the main numerical results \url{https://anonymous.4open.science/r/llm-local-meaning-diagnostics-FDF7/}. The appendix specifies each evaluation unit and the limits of the source review.
